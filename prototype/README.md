# Dr. Hematite — 火星版Polytopiaの画面・操作試作

`index.html` をブラウザで開く。ビルド、インストール、外部通信は不要。表示・ルールのコードはこのフォルダにある。再読み込みすると初期状態へ戻る。

## 操作

- 地図のマスをクリック／キーボードで選ぶと、可能な調査・移動・建設が右に出る。
- 上部の「研究ロードマップ」で別ページへ。24技術の前提、用途、素材、3コマのミニ解説を見られる。
- 研究後に地図へ戻ると、対応する設備の建設が可能になる。
- 「ターンを進める」で収入、生産、消費、移動権の回復、イベントが進む。
- 「全域を見る」は画面を確認するための俯瞰表示。通常は基地とローバー周辺を見渡す。
- 「開拓の記録」で調査・研究・建設・イベントをストーリーボードとして振り返る。

最初に試す流れ：選択中の氷候補を調査→研究ページで氷の採取を研究→地図で氷採取場を建設→ターンを進める→融解・浄化を研究→採水場へ改良。

## 動いているルール

- ターン制と、研究・調査・建設で使う共通開発ポイント。初期12、最初の拠点収入は3/ターン。
- 拠点の周囲で施設を作ると発展度が増える。必要発展度はレベル+2、レベルアップで収入と領地が増える。
- 技術は前提が必要。研究費は基本費用＋（自拠点数−1）×（列番号+1）。これは試作の調整式。
- 資源候補は現地調査で確認。研究済みの技術で適した場所に設備を建設。
- 設備は入力素材と電力がある場合に稼働。水・酸素・栽培を優先して処理する試作仕様。
- 太陽電池・蓄電・採水・電解・金属加工・樹脂再生などを扱う。数量はゲーム上の仮単位であり、反応式のモル比を表す値ではない。
- ローバーは1ターンに1回移動。起伏走行を研究すると距離が伸びる。無人拠点へ到達して開発ポイントを使うと拠点を確保できる。
- ターン3に予報、5〜6に砂嵐、7で回復する。動作確認用の固定イベントで、完成版のランダム性を意味しない。
- 砂嵐を越えたターン8から、架空のライバル勢力が行動する。巡回ローバーは隣接地へ1ターンに1回移動・攻撃でき、製作には開発ポイント4と樹脂か部品1が必要。
- 巡回機・拠点の耐久は3。全ての競争拠点を確保すると勝利、全ての自拠点を失うと敗北。対戦AIと数値は遊びの検討用の簡易実装。

## まだ実装していないもの

保存、ランダムイベント、実観測の地図接続、外部の教育動画。PHBの実製造と完全自給は実装していない。生命維持の不足は記録し、試作を継続できる設定。

研究の「ミニ解説」は文字と記号を順に見せる3コマの説明で、実験映像ではない。動画を見ることを研究の解放条件にはしていない。

## 科学と地図

11×11の地形、資源配置、勢力名、素材単位、設備能力は架空のゲーム設定。NASAの観測をこの局地図に投影したものではない。[科学資料](../docs/science/SCIENCE_ROADMAP.md)と[資源地図](../docs/science/NASA_RESOURCE_MAPS.md)で、観測・現実の工程・研究構想を区別する。

## 確認

Chromiumで `index.html?test` を開くと、`tests/smoke.js` が操作を確認し、末尾に結果を出す。結果は [tests/result.json](tests/result.json) に保存。13項目が通過：画面切替、研究条件、調査、建設と成長、移動と拠点確保、素材・電力不足、砂嵐からの回復、解説操作、巡回機の製作と戦闘、AIの行動開始、勝敗など。

通常の閲覧に `?test` は不要。地図の全景は `?overview`、研究の画面は `?view=research`。

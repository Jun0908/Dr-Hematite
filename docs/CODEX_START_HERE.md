# Codexへの最初の依頼文

> 現在はユーザーの指示に基づき、火星版Polytopiaの操作試作を進めています。地図が主画面、研究ロードマップは別ページです。[試作](../prototype/index.html)と[設計](design/MARS_POLYTOPIA.md)を確認してください。

Dr. HematiteはNASA Space Apps Challenge 2026向けの科学教育ゲームです。火星の素材を探し、化学・加工・発明をつなげて文明を発展させる体験を核にします。小学生高学年〜高校生が説明書なしで遊べるUIを目指します。

まずルートの[README](../README.md)、[AGENTS](../AGENTS.md)、[現在地](CURRENT_STATE.md)、[決定記録](DECISIONS.md)を読んでください。科学については[NASA資源地図](science/NASA_RESOURCE_MAPS.md)と[発明ロードマップ](science/SCIENCE_ROADMAP.md)を最優先で確認してください。

操作試作には探査、資源の採取・加工、24技術の研究、設備建設、拠点の発展、巡回機による競争と簡易勝敗があります。初回の砂嵐は固定イベントで、砂嵐後にライバルが動き始めます。現状と未実装範囲、ブラウザテストは[試作のREADME](../prototype/README.md)に記録しました。

11×11の地図、資源配置、陣営、数値、勝利条件は試作値です。NASA実観測地図は接続しておらず、観測で言えることとゲーム上の仮定を明確に分けてください。今後は、科学・発明が遊びの選択に十分効いているか、対戦・生命維持・イベントのバランス、対象年齢への分かりやすさを検証します。過去の[ゲーム性の3案](design/GAMEPLAY_THREE_OPTIONS.md)は比較の履歴として参照できます。

4 Agentsは必要時に使える手段で、常時並列分業する前提ではありません。

# PROJECT BRIEF — Dr. Hematite

背景と体験の核をまとめた資料。具体的な遊び方は、2026-11-14作成の [現行コンセプト](design/GAME_CONCEPT.md)を参照。

## コアの約束

> 火星の地図上で「ただの赤い石」を見つけ、分析によってFe₂O₃（ヘマタイト）だと知り、さらに水・水素・熱・設備の関係を理解して鉄を製造し、修理部品に使う。その発明が宇宙飛行士の生存を助ける。

化学・地質学・工学が**知識問題ではなく、ゲームの道具**になる。『Dr.STONE』の材料と技術の連鎖、Polytopia/Civilizationの内政・都市の成長、サバイバルの危機管理から着想。ただしオリジナルの世界観・アート・メカニクスで構築する。

## 世界観（検討案）

- 火星に到着した宇宙飛行士と宇宙船の限られた食料・水・酸素・電力・交換部品。
- 地球から運んだ生命維持、工具、科学機器、ローバー、3Dプリンタ／予備樹脂などが初期文明の核となる。
- ローカルな火星探査は地下氷候補地、レゴリス／鉄・ケイ素を含む岩石、火星大気のCO₂から始まる。
- 技術発展で採取→精製→反応→部品→設備→自給・内政の循環が発生する。
- NASAの資源分布図と実証技術をベースにしつつ、採掘収量・距離・工程時間はゲームとして抽象化可能。

## 想定ユーザー

小学生高学年から中学・高校生（上限は固定しない）。初見でも遊び始められ、理解が深まると元素・化学式・エネルギー・質量保存まで学べる。

## 今期待するプレイヤー体験

- 緊急事態に「次は何を発明すればいい？」と考える。
- 研究の進展で、既知の資源の用途が拡張される。
- 自分で作った酸素製造／採水／リサイクルなどの装置が目に見えて働く。
- ランダム事故を予報・備蓄・技術の冗長性で乗り越えられる。
- 内政で生産能力・研究力が育ち、宇宙船1機から火星基地へ見た目が発展する。
- 複数の攻略方針を試したくなる。

## 実装前の問い

大きな研究ロードマップの魅力を保ち、最初の砂嵐から遊び始める。以後のランダムな出来事と、自分で目指す発明が研究の順序を変える。情報はチュートリアルなどで小出しにし、短い道筋から複数系統のつながりへ理解を広げる案を検討する。経済、時間の進行方式、必要資源量、作業時間、最終目標は未決定。比較候補は [GAME_DESIGN_OPTIONS.md](design/GAME_DESIGN_OPTIONS.md)を参照。

# クレーター地形と山マスの改修

更新：2026-11-14。実装済みの規則と残る検証を区別する。観測データの出典は[地図出典](../../game/assets/sources.md)、数値は[ゲーム規則](../../game/RULES.md)を参照。

## 実測地形と旧ルールの問題

Arcadia PlanitiaのHiRISE DTMから約2.61 km四方を11×11マスへ集約した。標高中央値は最高約-3892m、最低約-4231mで、盤面内の差は339m。地図の陰影と色差は表示のために強調している。

旧ルールは隣接高低差を通行条件にしたため、観測ローバーは121/121マスへ到達できても、工作クローラーは102/121マスにとどまった。入れない西側の谷19マスには鉄原料候補 `(3,5)` とレゴリス候補 `(2,4)` が含まれた。初期の氷候補 `(3,7)` はローバーの斜め前にあるが、角抜け制限と移動タップ優先の組み合わせで、最初の調査操作が分かりにくかった。これは改修前の結果であり、現在の到達範囲ではない。

## 現在のゲーム規則

- 実測標高は地図の描画とマス詳細に残す。高低差は移動の可否を直接決めない。
- 通行障害は独立した2つの山マス `(4,6)`・`(6,4)` に絞る。他の地表はどの機体も通れる。最初の氷候補は山で囲まれていない。
- 前提なし・開発力4の「登坂技術」を研究すると、両陣営とも山マスへ移動・建設でき、山越えの補給路も使える。未研究なら山を迂回する。山は研究後も通信とセントリー射線を遮る。
- 最初の氷候補は地図で強調し、開始時にローバーを自動選択しない。ローバー選択中でも未調査の資源をタップすると、移動より調査操作を優先する。候補地に建設できない段階では建設ボタンを出さない。
- 旧クレーター版の保存対戦は、手番・研究・資源・調査結果を保ち、旧地形区分を新しい山マスへ置き換えて継続する。旧画像盤面の保存キーは別に残す。

山マスの位置、研究費、資源候補、通行・補給・通信の効果は**ゲームの抽象化**。HiRISEの標高値だけで、特定マスの車両通行可否や鉱床は確定できない。初期の砂嵐と後続イベントは従来のルールを維持する。

## 検証と次の調整

ブラウザの日本語・英語で33件ずつの自動テストが通過。初期氷のタップ→調査→氷採取の研究→採取場建設、登坂前後の移動と補給、保存対戦の規則移行を確認した。初期画面は[スクリーンショット](../../game/tests/screenshots/mountain-first-scene-ja.png)を参照。

山をどこに置くと「迂回するか、研究して近道するか」が面白くなるかはまだ試遊で確かめていない。両陣営の開始位置を交換した公平性、山に建てる価値、補給と通信の範囲表示、実機のタップ・パン・ピンチ、対象年齢の初見理解を評価する。高地の発電量増加や谷底の放射線防護といった効果は、裏付けなしには付けない。

当初検討した連続段差と「崖に昇降路を建てる」案は、初手の詰まりを解消する今回の規則には採用していない。今後、実測地形をさらに戦術へ結び付ける場合も、初期資源への到達性を先に確認する。

# 共通イラストと状態表示（Task2 U04）

更新：2026-11-14。ゲーム用の絵は[icons.js](../../game/icons.js)で独自に描いたSVG。Polytopiaの添付画像は画面情報量の比較に使用し、画像・キャラクター・アイコンを転用していない。NASAの観測画像とも別のゲーム用表示である。

| まとまり | イラストの区別 | 使う場所 |
|---|---|---|
| 生命維持 | 氷は結晶、水はしずく、酸素・水素は文字を付けた別色タンク、食料は葉と栽培容器 | 地図候補、HUD詳細、研究、教材 |
| 原料・加工品 | 原料は不規則な赤褐色の塊、金属は整形したインゴット、レゴリスは地層、建材は積み石、廃樹脂・再生樹脂・部品はそれぞれ破片・容器・歯車 | 地図、製作費、研究、教材 |
| 稼働設備 | 太陽電池は格子面、蓄電は電池、電解装置は二つの電極、温室は透明ドーム。採取場・還元炉・工房も装置の輪郭で分ける | 地図、研究で解放する装置、製作費 |
| 機体 | 観測ローバーはマストとカメラ、工作クローラーはアーム、セントリーは展開面と照射方向 | 地図、製作、研究、教材 |
| 拠点 | 中枢はドームと入口、無人前哨地は旗 | 地図、占領、記録 |

同じIDのイラストを地図・研究・費用・学習ページで使う。小さな地図では輪郭を優先し、教材では大きく表示する。地図の機体絵はマスの約80%、研究ノードは幅150×高さ120 CSS px、費用の絵は約23 CSS px、教材の選択札は約42 CSS px。文字だけで種類を判別しなくてよいよう、形と短い名前を併記する。

## 状態の表示規則

- **陣営**：アレスは青緑の縁と右上の三角旗、ベガは赤珊瑚の縁と菱形の旗。機体・基地・設備に同じ所属印を置き、選択札と読み上げ名にも所属を出す。
- **選択**：淡黄色の太枠。**移動可能**：青緑の塗りと枠。**攻撃可能**：赤い塗りと枠。候補は実行判定と同じ関数で作る。
- **研究**：研究済みは青緑、研究可能は琥珀、前提不足は暗色、将来枝は破線。選択した目標への前提線は明るくする。色だけでなく文字の状態名も出す。
- **稼働・損傷・強化**：故障は灰色と赤縁、停止設備は「!」と停止理由。損傷は赤い斜線と残り耐久。金属で強化した工房と工作クローラーは金属材の小さな札。行動済みの機体は低彩度。展開済みセントリーは光る外枠。
- **観測と仮定**：HiRISE写真の上に置く資源・施設・戦力はゲームの仮定。氷などの候補は調査前に「?」を重ねる。

ブラウザ相当の390×844、360×780、844×390、780×360 CSS pxで確認した。対象年齢の初見識別テストと実機での色・日光下の視認性テストは未実施。

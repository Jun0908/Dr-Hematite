## パラメーターを決める基準

水・酸素・電力は生命維持の重要な値だが、それだけでは「不足を補う」という判断に寄りやすい。食料に加え、何を増やせば未来の行動が増えるのかを設計する。候補は生産能力、研究の進展、使える素材、探査範囲。以下の3案では、成長の中心に置く値を変える。

| 値の種類 | 例 | 主な見せ方 |
|---|---|---|
| 消費・生産する在庫 | 水、酸素、食料、処理済みの鉄、樹脂、蓄電量 | 生命維持は上部、材料は対象の設備や製作画面。在庫と増減を表示 |
| 一定期間にできる量 | 生産力、設備の処理量、輸送能力 | 基地・設備・ローバーを選んだとき。容量と現在の使用量を表示 |
| 進歩と能力 | 個別研究の進捗、製造技術、断熱性能、移動能力 | 研究ページや装備画面。消費する共通通貨にはしない |
| 結果を表す指標 | 自給率、行ける範囲、完成した発明 | 成果や振り返り。複数の実態から求める |

水・酸素・食料を平均した「生存値」は使わない。まとめて表示する場合も、最も不足している項目と各在庫に戻れるようにする。電力は発電と需要の差、蓄電は残量として区別する。表面の簡潔さを、原因が分からない隠し計算で作らない。

初期画面は生命維持の小さな表示群と、その案で最も大事な判断用の値に絞る。元素・素材・機材の詳細は対象を選んだ場面で見せる。数が増えても、それを使う判断がなければパラメーターにしない。

## 案1：火星開拓文明 — 次の投資で、できることを増やす

### プレイの中心

地図で資源候補を調べ、採取拠点、工房、研究室、居住設備を育てる。今ある材料と生産能力をどこへ投資するかで、次にできることが変わる。文明を広く伸ばすか、一つの基地を高機能にするかを考える。

「探査→素材を使えるようにする→施設を建てる→生産や研究が進む→さらに大きな発明」が基本の循環。短いターンで進める方式を比較用に想定するが、時間方式は未確定。

### パラメーター

| 値 | 増やし方と使い道 | 生まれる判断 |
|---|---|---|
| 生産力 | 工房・工具・自動化で増える。建設・製作・修理の進捗に配分 | 将来の工房を増やすか、今必要な設備を作るか |
| 個別研究の進捗 | 研究設備の稼働、標本の分析、試作で進む | すぐ使える改善か、将来の素材技術か |
| 素材在庫 | 探査・採取・精製・再利用で得る。用途に合う素材を製作で消費 | 貴重な樹脂を修理に使うか、将来の装置に残すか |
| 水・酸素・食料・電力 | 生命維持と設備運転を支える | 成長のために、どこまで余裕を使えるか |

生産力は材料を生む魔法のポイントではなく、製作を進める能力の抽象化。研究の進捗は研究ごとに蓄積する。さらに同じ役割の共通DPを重ねない。基本の操作は「場所を選ぶ→計画を選ぶ→完成と効果を見る」。

### 4場面のプレイ例

1. NASA観測から氷の有望地域を調べ、探査で採取条件を確かめる。手元の基地設備と運搬距離を見て、採水拠点を計画する。
2. 余った材料で工房を拡張すれば次の建設が速くなる。しかし、研究室を先に動かせば、いま持っている鉱物の使い道が増える。今回は工房を選ぶ。
3. 生産能力が増え、現地材料を使う部品の試作が進む。適切な工具や部品を作れれば、採取・整備の効率が上がる。基地の見た目も変わる。
4. 新しい資源候補が見つかる。遠くに第二拠点を置くか、輸送路を整えて今の工房へ集めるかを選ぶ。

同じ地図でも、研究を先に進めたプレイヤーは別の技術や立地から成長できる。工房投資が常に正解にならないよう、材料・電力・設備を置ける場所・輸送維持の条件を合わせる。

### 砂嵐と長期目標

砂嵐の前に蓄電や備蓄へ生産を振るか、予定していた工房を完成させて復旧に備えるか。集中型の基地と、供給源を分散した基地では対処が変わる。

長期目標の候補は、複数拠点の安定運用、現地の材料で交換部品を製造できる工業基地、栽培まで含めた居住地。文明の段階は「現地水を供給できる」「材料を加工できる」など、実際に増えた能力で表す。

### 学びと弱点

土地の価値が技術で変わり、素材を知ることが立地や投資の判断に役立つ。最も大きなリスクは、材料製造が見えなくなって単なる施設購入ゲームになること。初めての材料・装置は「原料→処理→使える物」の工程を体験し、繰り返しは自動運転にする。

## 案2：火星の発明工房 — 素材の流れをつないで文明を動かす

### プレイの中心

地図に採取場、処理設備、工房、温室を置き、供給先を選ぶ。水から酸素と水素、水素から鉄の還元研究、加工した部品から設備の拡張へと、物の流れが広がる。

同じ材料を複数の用途へ配分し、どこが足りないかを改善する遊び。地図上で「ここからここへ送る」と操作し、細かな配管を一本ずつ引く必要はない。

### パラメーター

| 値 | 変化と使い道 | 生まれる判断 |
|---|---|---|
| 素材ごとの在庫・生産量・必要量 | 採取と加工で変化。設備選択時に入出力を表示 | 水を電気分解に回すか、温室を広げるか |
| 電力余力・蓄電量 | 設備の稼働で需要が増える | 生産設備を増やすか、効率や運転時間を調整するか |
| 輸送能力 | ローバーや輸送設備を割り当てる | 原料を工房へ運ぶか、現地処理設備を建てるか |
| 設備の処理能力 | 大きさ、稼働、改良で変化 | 採取を増やすか、詰まっている精製工程を改善するか |
| 生命維持の在庫 | 共通の水・酸素・食料 | 工業への配分と、人の暮らしを両立できるか |

素材の品質や耐熱性は必要な製品を選んだときに見せる。すべてを一本の「素材ポイント」へ交換可能にはしない。研究は関連する分析・試験を経て工程を使えるようにし、万能の研究通貨は設けない案。

### 4場面のプレイ例

1. 氷の採取と水処理が動き始める。酸素を作ると、水素にも用途があることが分かる。
2. 分析済みの鉄酸化物について、水素を使う還元工程を研究する。熱と反応装置も必要なので、水素だけでは製造できない。
3. 製作した加工設備を動かすと、今度は運搬が追いつかない。ローバーの積載・輸送を改善するか、処理設備を資源側へ移すかを考える。
4. 得た鉄系材料を加工して用途に合う部品を作り、設備を増設する。以前は邪魔だった余剰物に用途ができ、基地全体が動くようになる。

### 砂嵐と長期目標

発電量が下がったとき、どの工程を先に止め、何を備蓄でまかなうかを選ぶ。普段の効率を優先した設備と、余裕や別系統を持つ設備では結果が変わる。

長期目標の候補は、部品を現地製造できる工房、水回収と栽培を組み込んだ居住設備、複数地域へ物資を届ける生産網。地球からの持ち込みがどれだけ必要かを減らす進歩を見せる。完全な資源循環や無限の生産とは表現しない。

### 学びと弱点

素材・エネルギー・工程の関係が、そのまま上手に遊ぶ知識になる。奥深さは物の流れの競合や再利用から生まれる。弱点は管理量と操作の反復。止まった設備に原因を一つずつ表示し、一度作った工程は自動化する。隣接効果は輸送や利用できる熱など、説明できる理由があるときに使う。

## 案3：火星科学探検隊 — 発明するたび、世界が広がる

### プレイの中心

地図で「行ってみたい場所」を選び、探査・採取・試作で道具を作る。道具によって移動距離、滞在できる時間、採取・分析できる素材が増え、次の発明につながる。

探検の計画と帰還、その成果で基地を育てることが一つの区切り。輸送や支援基地を整えると、以前は危険だった経路が日常の活動範囲になる。

### パラメーター

| 値 | 変化と使い道 | 生まれる判断 |
|---|---|---|
| 隊員・ローバーの稼働枠 | 探査、分析、工作、整備に割り当てる | 今回の探査へ出すか、次の装備を作るか |
| 遠征の電力・生命維持の備え | 距離、活動、環境によって消費。帰還分も計画に含める | 遠くまで調べるか、余裕を残して帰るか |
| 積載量 | 装備、備蓄、回収する試料の合計で使う | 多くの材料を持ち帰るか、分析装置を積んで現地評価するか |
| 装備の性能・対応する作業 | 作った部品や技術で増える | 断熱、採取、分析、運搬のどこを改良するか |
| 基地の素材・生命維持在庫 | 探検の成果と日常の生産で変化 | 次の遠征か、工房や居住設備の拡張か |

地図には往復可能な範囲や、未確認の条件を見せる。研究進捗は「何を観測し、何を試せたか」と結びつける。科学の反応則や製作条件は毎回同じで、見つかる素材・発見順・出来事によって進路が変わる。

### 4場面のプレイ例

1. 地図に気になる鉱物候補地があるが、今の装備では遠征の余裕が少ない。近い地点を詳しく調べるか、遠征用の装備を先に改良するかを選ぶ。
2. 採取した材料を分析し、断熱材や部品の候補として試す。試験の結果、使える用途と足りない条件が分かる。
3. 適した素材と持参機材を組み合わせてローバーや探査装備を改良する。航続距離や活動可能な範囲が変わり、地図の奥へ行けるようになる。
4. 新しい素材を持ち帰り、基地に製作設備を作る。支援拠点と輸送経路も整い、小さな遠征隊の活動範囲が地域の文明に育つ。

### 砂嵐と長期目標

遠征中の予報を受け、帰還、既存の避難場所で待機、予定の変更を選ぶ。通信や支援拠点への投資が、この判断を変える。未知の事件を突然重ねて帰還不能にする設計は避ける。

長期目標の候補は、複数地域を結ぶ探査・補給網、現地材料による遠征装備の製造、安定運用できる第二基地。新しい土地へ行くだけで終わらず、成果が永続する設備や暮らしへ変わることを条件にする。

### 学びと弱点

「あそこへ行きたい」「この道具が欲しい」が、材料を調べる動機になる。NASA地図の推定と現地確認の違いも行動から学べる。弱点は文明建設が脇役になりやすいこと。地図の行動範囲と、基地の製造・生活能力の両方を成長として扱う。

## 追加の有力案：火星版Polytopiaと、動画を見られる研究ツリー

ユーザーから「火星版Polytopiaはどうか」「研究ツリーにビデオなどを入れて教育として学べるようにしたい」という提案があった。案1を具体化する有力な方向として検討する。採用決定や、Polytopiaの仕組みをすべて移植する指示ではない。

### 基本の遊び

地図上の場所を選ぶと、探査・採取・施設建設・設備運転など、その場所で可能な行動が分かる。発明によって新しい用途が開き、同じ地図の価値が変わる。研究ロードマップは別ページ。砂嵐などの出来事と成果はストーリーボードで伝える。

一例は、氷候補を調査する→水処理設備を動かす→電気分解を研究する→酸素供給と水素利用へ広がる→鉱物分析・熱・反応装置を用意し、鉄の還元と加工へ進む→現地製の部品が基地やローバーに使われる、という成長。科学的な条件は既存の科学資料に従う。

### 最初に試す経済の別案

案1の生産力と研究進捗を詳しく扱う方式に対して、探索・研究・建設への投資を共通の「開発ポイント」にまとめる方式も比較する。

- 開発ポイント：基地の開発に使える余力を抽象化した予算。稼働する拠点や工房の成長で供給が増える。研究・探索・建設のどこへ使うかを選ぶ。実物の物質や電力には換算できない。
- 素材在庫：水、処理済みの鉄、樹脂など。製作対象を選ぶと必要な種類と量を表示する。開発ポイントだけでは製品は作れない。
- 電力：設備を稼働させる供給と需要、蓄電残量を扱う。
- 生命維持：水・酸素・食料を小さな表示群にまとめる。内部では別々の在庫・収支で、どれが足りないかが分かる。

この方式では同じ作業に生産力ポイントと人手ポイントをさらに課さない。研究には関連する観測や標本、必要な試作条件も関わる。ポイントは研究の計画・作業の抽象化であり、原料や設備を不要にするものではない。供給量、持ち越し、成長による増加、研究コストは未決定。

### 研究ノードの中身

技術を選んだ最初の画面には「何ができるようになるか」「必要な素材と装置」「この技術を使える地図上の場所」を見せる。短い説明動画を開けるボタンを置き、詳しく知りたいときは化学式や出典へ進む。

動画の例は、水と電力が電解装置へ入り、酸素と水素が別々に出て、それぞれ基地や別の研究につながるアニメーション。短い動画の長さは15〜30秒程度を試す案。字幕と静止図でも同じ内容を見直せるようにする。

動画を見たこと自体では技術を解放せず、見た内容を製作や配分の判断に使えるようにする。視聴は任意で再生し直せる。動画を開いている間は判断を急かさない。具体的な動画の制作・選定・実装はまだ行っていない。

### この方向で確かめたいこと

「地図を触って基地を育てる」「次に作りたいものを研究ページで見つける」「知った科学を地図上で使う」が自然につながるか。共通ポイントで操作が分かりやすくなっても、素材から作る実感が薄まっていないかを優先して確かめる。

## 面白さを確かめる比較試作

同程度の初期備蓄、資源候補、持ち込み装置を使った短い試作を3案で比べる。試作時間、マス数、技術数は比較のための範囲であり、企画全体の科学の幅を決める値ではない。

1. 災害がない状態でも、次に作りたいものと複数の進め方があるか。
2. 同じ備えの状態から砂嵐が来たとき、異なる対処を選べるか。
3. 一つの発明で、地図上の行動と基地の能力が実際に増えるか。
4. 素材の役割を理解した人が、別の場所や製品にもその知識を使えるか。
5. プレイヤーが失敗の原因を特定でき、自分の方針を修正できるか。

「次も遊びたい」「別の方法を試したい」と、自力操作・科学の理解を別々に観察する。テスト前に面白さや教育効果を実証済みとしない。

## 共通する科学の扱い

NASAの広域観測は候補地を考える根拠であり、ローカルなタイルの収量を直接決める地図ではない。氷候補と遠く離れた鉱物観測地を、実在の近隣地点として配置しない。観測・推定・仮想の地形と収量を区別する。

鉄の還元、ガラス、樹脂再生、PHBなどの工程条件・実証状況は既存の [SCIENCE_ROADMAP](../science/SCIENCE_ROADMAP.md)、[SCIENCE_RESEARCH](../science/SCIENCE_RESEARCH.md) に従う。火星材料だけで電子機器を含むすべての設備を直ちに製造できるとは扱わない。持参した機器を利用し、現地製造できる部分を増やす文明の進化として表す。

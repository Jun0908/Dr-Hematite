# 初期生命維持と資源収支の見直し

2026-11-15。ユーザーの指摘に基づく試作調整。数値の最終採用・対戦バランスの合格を意味しない。実装は [game.js](../../game/game.js)、現行規則は [RULES](../../game/RULES.md)。

## 指摘と原因

水・酸素・食料が切れると敗北するのに、初期の本拠地にはそれらを作る装置がなかった。氷採取場と太陽電池を作っても、加工装置がなければ水は増えない。さらに在庫の差だけを示していたため、作った物が次の工程や生活で消費されたのか、そもそも生産されなかったのかが分からなかった。

添付された旧画面は氷+2、水・酸素・食料−1、再生樹脂+1だった。この表示だけでは、採水・電解・温室の有無や停止原因を特定できない。今後は実際の生産処理から、装置の入力・出力・停止理由と、在庫に残る量を説明する。

## 試作に反映した開始条件

両陣営とも、稼働済みの氷採取場、採水設備、電解設備、温室、追加太陽電池2基、蓄電設備1基から始める。氷採取・融解浄化・電解・栽培・蓄電は初期技術であり、研究ツリーから科学教材も読める。水・酸素・食料は各12、部品8、開発力16、蓄電7。装置は持参した初期装備として数え、建設費を引かない。種・養分・保守資材などの条件は従来の教材・科学資料で説明する。

通常時の発電12に対し、居住区2・氷採取1・採水2・電解2・温室2で計9を使う。

| 生活資源 | 生産 | 加工で使用 | 生活で使用 | 在庫の差 |
|---|---:|---:|---:|---:|
| 水 | 3 | 電解1＋栽培1 | 1 | 0 |
| 酸素 | 2 | 0 | 1 | +1 |
| 食料 | 2 | 0 | 1 | +1 |

初期装備は生活を成立させるためのもの。水の余裕、金属、部品、前線の拡張は投資して作る。供給を失う、装置が故障する、増設で電力が足りなくなると備蓄を使う。最初の砂嵐だけで無操作の初心者を退避させない。

## 資源どうしの関係

| 欲しいもの | 入手・生産の経路 | 競合・制約 |
|---|---|---|
| 氷 | 地図の資源を確保・調査し、採取装備を配備 | 接続拠点を失うと搬入停止。電力1で氷2 |
| 水 | 氷1＋電力2 → 採水設備 → 水3 | 飲用・電解・栽培で共用 |
| 酸素・水素 | 水1＋電力2 → 電解 → 酸素2＋水素1 | 水素は金属還元にも使う |
| 食料 | 水1＋電力2 → 温室 → 食料2 | 温室増設だけでは水が不足することがある |
| 金属 | 奪い合う鉱物地点 → 原料、原料1＋水素1＋電力3 → 還元炉 → 金属1 | 調査・鉱物分析・還元研究・設備・電源が必要 |
| 部品 | 持参の廃樹脂 → 再生樹脂、再生樹脂1＋電力1 → 印刷工房 → 部品2 | 初期の廃樹脂3・再生樹脂2は有限。建設・機体・修理で使い合う |
| 建材 | 地図のレゴリス → 採取・焼成 → 建材 | 中枢の補強へ。電力・部品を金属路と配分 |
| 電力 | 基礎太陽電池＋追加太陽電池。余剰分を蓄電 | 電源だけで物資は増えない。満充電後の余剰は貯まらない |

数量はゲーム上の値。科学の条件や実証範囲は [SCIENCE_ROADMAP](../science/SCIENCE_ROADMAP.md)、局所資源と実観測の区別は [NASA_RESOURCE_MAPS](../science/NASA_RESOURCE_MAPS.md) を参照。

## 増設と対戦の調整

- 採水設備1基を開発力4・部品1で増設すると、平常時は水が差し引き+3になる。追加で氷1と電力2を使う。
- 温室1基だけの増設は食料+3、水−1となる。水と電力の確保を同時に考える。
- 太陽電池1基は発電+3。平常時の初期設備の生産量は変わらないが、最初の砂嵐で全生命維持装置を稼働できる余裕を作る。
- 無人Podは水・酸素・食料を消費しない。接続Podごとに電力1を使い、取得直後に生活物資が説明なく減る仕様を廃止。
- 生産順は氷→水→酸素／食料→工業用原料→加工。産業の拡張で基本生命維持を先に止めない。酸素／食料の優先選択は残す。
- 敗北猶予は実際に生活必要量を満たせなかったラウンドだけ数える。作って使い切ったため在庫0でも、必要量を満たしたなら欠乏ではない。

## 確認と未評価

[収支計算の結果](../../game/tests/economy-results.json)では、初期・太陽電池増設・採水増設・温室増設を各6回進行して比較。初期だけでも最初の砂嵐を越え、太陽電池1基追加では生命維持装置の停止を防げた。採水増設の水+3、温室増設の水−1を確認。

通常コスト・実際の移動と調査で3ターン目にPodと鉱物地点を確保し、5ターン目に還元炉を建設、砂嵐後の7ターン目に金属1を生産する経路も確認した。部品は初期再生樹脂を使い、研究と工房建設の費用を払って2ターン目に2個生産できる。

これは経済の成立確認であり、最適解や勝利戦略の証明ではない。長期の在庫量、廃樹脂・部品の枯渇、両開始位置、敵との駆け引き、対象年齢の初見理解は継続評価が必要。

## 土台にするルール

| 構造 | 火星版での表現 |
|---|---|
| タイルを選んで行動する | ローバーの移動・現地調査・採取・施設建設 |
| 共通ポイントで研究や開発を選ぶ | 拠点から開発ポイントを得て、探査・研究・建設に配分 |
| 土地を開発して拠点が育つ | 採取場・工房・温室などで発展度が増え、収入と領地が増える |
| 技術で新しい行動が開く | 原料の処理、装置の設置、移動や輸送の改善 |
| 拠点を増やす | 無人前哨基地へ到達して確保する。研究費も拠点数に応じて増える |
| 他勢力との競争 | 架空のライバル拠点と巡回機を配置。無人機の移動・攻撃、簡易AI、拠点の勝敗を試作 |

この表は類似した遊びの構造を火星向けに具体化した設計。Polytopiaの全仕様・最新数値を完全再現したという意味ではない。参考：[Polytopia公式](https://polytopia.io/)。

## 火星素材と文明の進化

共通ポイントに加えて、素材は種類ごとの在庫として持つ。設備の材料変換には電力と入力が必要。鉄や樹脂などをポイントで自由に代用しない。

地図には氷候補・鉱物候補・レゴリスがあり、現地で確認して利用を進める。持参した装置を出発点に、火星で作れる部分が増える。科学を調べると同じ土地に新しい価値が生まれる。

地図は11×11の仮想地域で、NASA観測データとの接続は未実装。科学上の原料と工程の関係は [SCIENCE_ROADMAP](../science/SCIENCE_ROADMAP.md)を参照する。

## 研究ページ

24技術を6系統に配置した：探査と輸送、水と化学、鉱物と金属、地表から建材へ、樹脂と製造、電力と暮らし。点線は別系統の前提研究。各ノードには用途、入力と装置、文字と記号による3コマのミニ解説、参考資料を置く。

水の電気分解→水素を使った鉄の還元、樹脂再生→印刷材料と部品製作など、系統のつながりを含む。PHBは将来の研究構想として表示し、火星での実証済み量産技術とは扱わない。

今回の24技術は最初の試作範囲。CO₂電解など既存の科学資料にある技術は、表示やルールを育てる際の追加候補として残る。科学ロードマップ全体を24技術に限定する決定ではない。

## 状態

地図と研究は動く試作を作成し、13項目のブラウザ操作テストを通過。初回の砂嵐はターン5〜6の固定イベントで、他勢力はターン8から行動する。巡回機の製作・移動・攻撃、簡易AI、勝敗を試せる。セーブ、ランダムイベント、本物の観測地図、実験動画は未実装。ミニ解説は3コマの文字・記号表示で、動画とは異なる。

陣営は架空の名称を使った。現実の国・組織が火星で交戦する事実を示すものではなく、競争の遊びを確かめるための仮設定である。勝利条件と対戦の重みは、科学・発明の面白さを損なわないか検証が必要。

## 企画の核

NASAなどの実観測地図で火星の資源候補を探し、火星素材の採取・加工・発明を連鎖させて文明を強化する。2チームが地図上のPodと原料を争い、相手の中枢基地の攻略または生命維持の断絶で勝つ。地図が主画面、研究ロードマップは別画面。Dr.STONE的な文明の進化と大きな科学の枝を維持しながら、最初の操作と教材は段階的に見せる。

## Task4で動くようになったこと

- 両陣営とも稼働済み氷採取場・採水・電解・温室・電源・蓄電から開始。資源一覧から地点へ進み、確保・調査・装備・搬入を確認できる。生活資源は生産／加工使用／生活消費と次ターンの残量を表示し、停止した装置と不足原料へ案内する。無人Podは生活物資ではなく電力を使う。
- HiRISE実測標高のArcadia Planitiaの11×11盤面を継続。最初の氷は採取装備まで設置済み。追加の資源へも登坂技術なしで進める。地図と研究は上下左右にパンできる。縦横の固定Header／Footer帯はない。
- 地図は調査・原料採取・Pod確保・戦闘へ整理。加工設備と発電設備は本拠地の別ページで建設する。本拠地の絵には建てた設備が増え、入力・出力・翌ラウンドの稼働予測を表示する。機体製作、故障修理、焼成建材による中枢補強も本拠地で扱う。
- 資源地点を中枢またはPodの担当区域へ割り当て、接続された採取点だけが陣営共通在庫へ搬入する。Podを選ぶと確認済み資源の切断・確保影響と確保費用が見える。切断時は備蓄を保持して搬入・補給が止まり、別経路で復旧できる。敵PodはHPを0にしてから工作機で確保する。占領者は旧採取装備を引き継がない。
- 氷→水→電解→酸素・水素、水→栽培→食料、CO₂→酸素、鉄系原料＋水素→金属、廃樹脂→再生樹脂→印刷部品、レゴリス→焼成建材の生産を処理する。酸素／食料の優先、砂嵐による発電低下、蓄電、故障、資源不足、3ラウンド連続不足の退避を維持する。
- 20ノードの研究ツリーを保持し、加工技術から本拠地、採取技術から地図へ送る。完成した12題材だけ英語の学習リンクを出す。電解・MOXIE・栽培・蓄電・鉱物分析・鉄還元・金属加工・焼成建材・樹脂再生の9図、工程ごとの説明、反応式、一問、題材別NASA資料を用意した。教材からゲームの費用・収量と定型注意欄を撤去した。旧原画は独立URLで残す。
- JP/EN切り替えを維持。提出向けの英語を先に整え、日本語UIから英語教材へ進む場合は「英語」と表示する。旧セーブは `hematite-arcadia-crater-v2` に残し、初期設備改修版は `hematite-arcadia-civilization-v5` に保存する。旧Task4の `hematite-arcadia-civilization-v4` も保全する。
- 今回は放射線イベントを抽選・勝敗に含めない。建材は中枢補強に使い、自動化は将来枝へ変更した。

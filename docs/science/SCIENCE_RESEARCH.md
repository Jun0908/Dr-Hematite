# SCIENCE RESEARCH — 科学的リアリティを高める資料

研究をゲームへ使う際、**観測済み／装置で実証／地球で実験／シミュレーション／架空のゲーム数値**を区別する。

## 1. 初期宇宙船の貨物

NASAは特定の有人火星ミッションの確定した汎用貨物リストを公開しているわけではない。ゲームでは居住区・ECLSS・酸素と水の備蓄・保存食・電源・蓄電池・ローバー・採掘機・分析器・工具・小型3Dプリンタ・予備樹脂・栽培装置などを**シナリオ上の想定装備**として考える。

## 2. 生命維持の最重要ポイント

- NASA ECLSSは水回収、空気再生、酸素生成などのサブシステムを持つ。[R8]
- ISSでは水回収率98%に達する実証結果がある。ただし火星基地で同じ値が無条件に再現するわけではない。[R9]
- CO₂からO₂を作るMOXIEはPerseveranceで計122 gの酸素、最高12g/時を製造（2023年発表）。**有人基地をそのまま支えられる生産能力ではない**。[R10]
- 太陽光は砂嵐／夜／設備の汚れに影響を受け、供給電力と消費電力の競合をゲームに活用できる。
- 食料栽培には水・栄養塩・光・温度・微生物／汚染などの管理が必要。初期の収穫は「完全自給」を意味しない。

## 3. 物理・化学の主な反応

- `2H₂O → 2H₂ + O₂`（水の電気分解）
- `2CO₂ → 2CO + O₂`（MOXIE系のCO₂電解、概略の正味反応）
- `CO₂ + 4H₂ → CH₄ + 2H₂O`（サバティエ反応）
- `Fe₂O₃ + 3H₂ → 2Fe + 3H₂O`（水素による酸化鉄の還元、条件付きの工程）
- 光合成の教育モデル `6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂`（実際の光合成は複雑な生物過程）

## 4. 3Dプリントと材料

NASAはISSで廃プラスチックを再加工しフィラメントにするReFabricatorのような研究を行った。[R11] 地球から携行した樹脂を再利用して修理部品を作るのはゲームに馴染む。強度・気密・耐熱など用途に応じた材質制限がある。

`Mars Seed`（Storkほか、2026-11-09、arXiv:2611.13064）は、火星の現地資源を使ったPHBバイオプラスチック製造の**設計研究（査読前プレプリント）**。[R12] ゲームの高度な発明系統として使えるが、火星での実機生産実証ではない。

## 5. 科学的に伝えたい不確実性

- 鉄元素の多い地図とヘマタイト鉱物の地図は別。鉱物の多さと採掘可能な鉱石は別。
- 地下氷の「候補地」と、試掘によって採取量が確かめられた場所は別。
- シリコン元素マップは純粋なシリカ鉱床の地図ではない。
- レゴリスだけで装置や良質なセラミックがすぐできるわけではなく、工程が必要。
- ゲーム内のDP、1ターンの資源減少、資源収量、技術コストは教育・ゲームデザインの仮定である。

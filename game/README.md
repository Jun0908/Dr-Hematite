# Dr. Hematite — Arcadia civilization duel

HiRISEの実測標高を用いた火星の11×11マスで、2陣営が資源・中継Pod・研究を争うモバイル向け試作です。素材から設備と機体を作り、相手の中枢基地を攻略します。提出向けの英語表示を優先しています。

## 起動

プロジェクトのルートで `node scripts/serve_game.js` を実行し、[英語版](http://127.0.0.1:8765/game/?lang=en)または[日本語版](http://127.0.0.1:8765/game/?lang=ja)を開きます。ビルド不要です。言語はゲームのメニューから切り替えられます。科学教材は現時点で英語のみで、日本語UIにはその旨を表示します。

## 遊び方

1. 氷採取・採水・電解・温室・電源・蓄電は設置済みです。水・酸素・食料の備蓄をタップすると、生産・加工で使用・生活で使用・次ターンに残る量が分かります。
2. 「資源・Podを探す」から追加の資源へ。工作機でPodを確保し、ローバーで調査、採取技術を研究、装備を配備します。地点のカードが次の操作へ案内します。
3. 氷などの原料はターン終了時に本拠地へ自動搬入。本拠地の装置で水・酸素・食料・金属・部品を作ります。「増やすには」から該当装置へ進めます。
4. 太陽電池は物資ではなく電力を増やします。建設前の比較で、生産の変化と停止理由を確かめます。温室は水を使い、還元炉は原料と水素を使います。
5. 敵PodはHPを0にしてから工作機で確保。相手の搬入を止め、自分の装備で資源を利用します。相手中枢の制圧維持、または生活必要量の3ラウンド連続不足で勝敗が決まります。

地図と研究ツリーは上下左右へパンでき、地図はピンチ・拡大ボタンにも対応します。固定のHeader／Footer帯は置いていません。本拠地と研究ページでは浮動の下部操作ボタンを隠します。PCブラウザでは地図を全体表示から始め、状態・操作・本拠地・教材を画面と表示倍率に合わせて拡大します。

## 画面の役割

- **地図**：HiRISE地形、調査、原料採取、担当区域、Pod接続、移動と戦闘。加工施設を地表マスに建設する操作はありません。
- **本拠地**：水・酸素・食料、電源、素材と製作の装置を建てます。装置の入出力、翌ラウンドの停止理由、機体製作、焼成材による補強を確認できます。建てた装置だけが基地の絵に増えます。
- **研究**：20ノードの発明ツリー。加工技術から本拠地、採取技術から地図へ進めます。完成した12題材だけ「仕組みを学ぶ」を表示します。
- **科学教材**：ゲームの建設費や収量を含めず、材料・装置・生成物を図と短文で説明します。電解、MOXIE、栽培、電源、鉱物分析、鉄還元、金属加工、焼成建材、樹脂再生の9種類の図解を12題材から開けます。各題材にNASAの解説・研究へのリンクを付けています。旧ロードマップの原画は独立ページで閲覧できます。

## 保存と検証

初期設備改修版は `hematite-arcadia-civilization-v5` に保存します。旧 `hematite-arcadia-civilization-v4` と `hematite-arcadia-crater-v2` は保全し、新しい初期条件で対戦を始めます。`?test&lang=en` でTask4の機能検証41件を実行できます。旧34件は旧ルール用の記録です。[規則](RULES.md)、[実施した検証](tests/PLAYTEST.md)、[Task4の進捗](../Task4.md)、[初期設備・収支の調整](../docs/design/LIFE_SUPPORT_BALANCE.md)を参照してください。

## 科学と地図の範囲

HiRISEの標高は実測データです。局所資源、基地位置、マス当たりの収量、設備の出力・費用、山マスの通行規則はゲーム設計です。SWIMは広域の地下氷候補を示す資料として教材と観測ページから参照できます。[地図の出典と加工](assets/sources.md)に詳細を記録しています。実機でのタッチ操作と対象年齢による初見評価、複数戦略のバランス調整は未実施です。
